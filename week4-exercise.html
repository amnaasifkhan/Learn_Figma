Week 4 Exercise

Basic Vector Editing in Figma

Exercise Overview

In this exercise, you will practice basic vector editing techniques in Figma by creating simple interface icons.

Task

Create the following icons using Boolean operations and refine them using Vector Edit mode:

  • 🏠 Home icon
  • 🔍 Magnifier (Search) icon
  • ✂️ Cut (Scissors) icon

Instructions

  • Start with basic shapes (rectangles, circles, lines)
  • Use Boolean operations (Union, Subtract, Intersect)
  • Adjust anchor points using Vector Edit mode
  • Maintain consistent size and stroke thickness
  • Align icons properly using guides and spacing

Design Guidelines

  • Use a consistent style (filled or outline)
  • Keep icons simple and recognizable
  • Ensure symmetry and alignment
  • Use grid or frame for consistency

Deliverables

  • Three completed icons (Home, Magnifier, Cut)
  • Well-organized layers
  • Use of Boolean operations
  • Refined vector paths

Reflection

Add a short note (3–4 bullet points) explaining:

  • Which Boolean operations you used
  • How you improved the shapes using vector editing
  • Challenges faced and how you solved them
