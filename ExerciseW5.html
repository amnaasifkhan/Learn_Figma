Lesson 5 Exercise

Prototyping, Components & Mobile UI Flows

Lesson 1 Lesson 2 Lesson 3 Lesson 4 Lesson 5

Overview

Complete three task flows and three screens from your assignment topics.

What you will practice:

  • Auto Layout and Components
  • Navigation bar and footer design
  • Vector editing basics
  • Multi-screen UI assembly
  • Vertical scrolling
  • Smart animations
Important:
You must demonstrate appropriate use of metaphors in your mobile UI design.

Step 1: Setup & Planning

  • Create a new Figma file with two pages:
    • Components
    • Screens
  • Add a mobile frame (e.g., iPhone 13/14)
  • Enable an 8px layout grid
  • Select content that fits 2–3 screens (e.g., list + detail)

Step 2: Build Reusable Components

Button Component

  • Use Auto Layout for padding and spacing
  • Create component with variants (optional)

Card Component

  • Combine title, text, and button
  • Use vertical Auto Layout

Navigation Bar & Footer

  • Use horizontal Auto Layout
  • Maintain consistent spacing

Vector Editing (Optional)

  • Create a simple icon using Boolean operations

Step 3: Assemble Mobile Screens

Screen 1: Home

  • Use Nav bar, Card instances, and Footer
  • Apply vertical Auto Layout
  • Enable scrolling if needed

Screen 2: List / Explore

  • List of card instances
  • Reuse Nav and Footer

Screen 3: Detail (Optional)

  • Expanded card layout
  • Enable scrolling

Step 4: Prototyping

  • Enable vertical scrolling
  • Add smart animations between states
  • Create flows:
    • Home → List
    • List → Detail
    • Add Back navigation

Step 5: Reusability

  • Use component instances only
  • Edit main components to update globally

Step 6: Final Checks

  • Consistent spacing (8/12/16px)
  • Working interactions
  • Visible animations
  • Readable text (basic accessibility)

What to complete:

  • Your Figma prototype with screen flows.
