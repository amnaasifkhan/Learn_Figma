Figma Beginner Course

7-Week Learning Plan for Interface Design

Week 1 Week 2 Week 3 Week 4 Week 5 Week 6 Week 7

Lesson 1 – Introduction to Figma Getting Started

  • Create a Figma Education account
  • Tour the file browser
  • Customize your profile
  • Create your first design file
  • Navigate the Figma interface
  • Set file preferences

Lesson 2 – Basic Design Elements

  • Create an avatar using shapes and fills
  • Build a personal bio using text layers
  • Add layers into frames
  • Create frames using frame presets
  • Create headings, paragraph text, and quote blocks
  • Create images and hero sections

Lesson 3 – Layout and Design Structure

  • Constraints fundamentals
  • Clean up and organize layers
  • Understand sections, groups, and frames
  • Create navigation bars
  • Create footer sections
  • Design responsive layouts
  • Auto Layout fundamentals
  • Create responsive buttons
  • Components fundamentals
  • Create reusable component instances
  • Create cards and container systems
  • Auto Layout tips and tricks

Lesson 4 – Auto Layout and UI Components

  • Combine shapes using Boolean operations
  • Use vector edit mode
  • Turn an ellipse into an arc
  • Create custom icons
  • Create a skills list component
  • Organize components using sections

Lesson 5 – Advanced Shape and Vector Design

Lesson 6 – Portfolio Layout Design

  • Assemble portfolio pages
  • Build home page layouts
  • Create case study pages
  • Use reusable components across pages

Lesson 7 – Interactive Prototyping

  • Prototyping fundamentals
  • Add prototype connections
  • Create navigation interactions
  • Set scrolling behavior
  • Customize animations
  • Test and preview interactive prototypes
