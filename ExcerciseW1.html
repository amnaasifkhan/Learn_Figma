Learning Objectives

By the end of this exercise, students will be able to:

  • Apply Figma skills, using layers, frames, text, and shapes to redesign and improve a portfolio layout.
  • Justify design decisions using usability and storytelling principles.

Instructions

This is an individual exercise.

  1. Select a Portfolio Template
    Visit the Figma Community templates: Figma Portfolio Templates.
    Example template: Portfolio Design (Community)
  2. Review the “Portfolio” Sample
    Spend about 5 minutes exploring the layers and frames to understand its structure.
  3. Identify Portfolio Problems
    Read the Learn UI Design article on portfolio mistakes:
    • Resource
    Identify at least three design or content mistakes in the sample portfolio that match issues mentioned in the article, such as:
    • Poor visual design
    • Overemphasis on process and deliverables
    • Too much text
    • No real-world results
    Add comments directly in the Figma file using the comment tool.
